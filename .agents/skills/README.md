# Habilidades del proyecto

Aquí se guardan habilidades locales que complementan las instrucciones globales de los agentes. Cada habilidad debe vivir en su propia carpeta y contener un `SKILL.md` con propósito, entradas, procedimiento, validaciones y límites.

Posibles habilidades futuras: validación de casos bancarios, importación de CSV regional y revisión de trazabilidad. No se añadirá una habilidad hasta que exista un flujo repetible y comprobable.
